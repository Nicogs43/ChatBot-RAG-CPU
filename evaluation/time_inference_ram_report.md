# Time Inference + RAM Report

## Scope
Analysis of the new inference outputs generated by `bin/time_inference.py` with RAM instrumentation:

- `data/inference_time/*_time_inference_new.csv`
- `data/inference_time/time_initialization.csv`

All values below are computed from the CSVs currently in the repository.

## New Column Meanings

### Per-inference file columns (`*_time_inference_new.csv`)
- `inference_time`: End-to-end time (seconds) for one `rag_chain.invoke(...)` call.
- `proc_rss_mb_before`: Python process resident memory (RSS, MB) immediately before inference.
- `proc_rss_mb_after`: Python process resident memory (RSS, MB) immediately after inference.
- `proc_rss_mb_delta`: `proc_rss_mb_after - proc_rss_mb_before` (MB) for that request.
- `sys_percent_before`: System-wide RAM usage (%) immediately before inference.
- `sys_percent_after`: System-wide RAM usage (%) immediately after inference.
- `sys_used_mb_before`: System-wide used RAM (MB) immediately before inference.
- `sys_used_mb_after`: System-wide used RAM (MB) immediately after inference.

### Initialization file columns (`time_initialization.csv`)
- `initialization_time`: Time (seconds) to initialize one model pipeline and RAG chain.
- `init_proc_rss_mb_before`: Process RSS (MB) before initialization.
- `init_proc_rss_mb_after`: Process RSS (MB) after initialization.
- `init_proc_rss_mb_delta`: Process RSS change during initialization (MB).
- `init_sys_percent_before`: System RAM usage (%) before initialization.
- `init_sys_percent_after`: System RAM usage (%) after initialization.

## Key Findings
- Fastest model by mean latency: `qwen_0.5b` (6.187 s mean, 10.363 s P95).
- Slowest model by mean latency: `gemma` (121.356 s mean, 299.703 s P95).
- Highest average process RSS footprint during inference: `gemma` (~10.0 GB mean after inference).
- Lowest average process RSS footprint during inference: `qwen_0.5b` (~3.49 GB mean after inference).
- `qwen_1.5b` shows negative mean `proc_rss_mb_delta`, indicating memory is often returned/reclaimed across requests.
- System RAM pressure is high during `gemma` and `qwen_1.5b` runs (around 96-98% mean system RAM).
